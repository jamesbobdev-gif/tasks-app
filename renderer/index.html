Mini PC server

When it's on, the agent, its browser, mail dates and calendar sync run on your mini PC. This computer only shows them and syncs, over Tailscale.

AI connections

Local model

Your own model through Ollama, on this computer or another one on your network. Nothing it works on leaves your machines. Tasks with private words always go here.

Who does Agent tasks

When no rule matches:

Auto: inbox, web, shopping → cloud. Writing, forms → the local model. Anything else → cloud, or the local model if Claude is near its limit. If a side is offline, the other takes it.

About you

What the Agent knows about you

Read before every Agent task. One preference per line. Keep private details out — put those in Locked below.

Locked — only the local model sees this

Resume, address, phone, IDs — for filling in forms. The Agent’s cloud AIs never read it. No passwords, card numbers or SSN.

Files for forms

Your resume (a PDF is safest), plus a transcript or cover letter if you like. They stay on this computer. When a job site asks for one, the Agent or the local model attaches it; nothing else on this computer can be uploaded.

Agent features

Morning look-ahead

Each morning the Agent reads the next two weeks of your calendar, last week's email and what it knows about you, and adds what needs doing to the Agent list. It only suggests; you reply to start it.

Hey Romulus

Say “Hey Romulus”, wait for the chime, then speak. Screen-on only; 40 MB one-time download.

Course calendars

Paste calendar links, one per line; due dates land on School. Blackboard: Calendar → ⚙ → Share Calendar. D2L: Calendar → Subscribe.

Device sync

Sync with your phone via a free Supabase project. One project, one sync key: the same three values on every device sync every list. Keep the sync key private.

Adding a device? Press Copy sync code here, then paste it into the first box on the other device: it fills in all three.

Per-list keys (optional)

The Work, Agent and School lists get their own keys made from the sync key above, so they sync wherever it does. Type a key here only to share one list with a different key (for example a Work list shared with a colleague).

Welcome to Romulus

A to-do list that works on its own. Everything else is optional. What would you like?

  • Drag a task to reorder it; tags group tasks and become filter chips.
  • The Agent tab hands tasks to an AI; the pill on each task picks which one.
  • School and Work are separate lists; Calendar, Ideas and Hours are extra views of the same tasks.
  • Closing the window hides Tasks in the tray by the clock; right-click the tray icon to quit.

You can change all of this later in ⚙ Settings. This card shows once.
